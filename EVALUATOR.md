# Independent Review Contract — Bazodiac Cinematic Investor Deck

Purpose: adversarial visual/content quality assurance on the ACTUAL rendered deliverable, not merely agent confidence or prompt compliance. Review `exports/contact-sheet.png`, full-resolution slide exports, working app, PDFs and source.

## Noncompensatory blockers

Any confirmed case below is BLOCKED regardless of visual beauty:

1. Unsupported scientific, clinical, personality, business, revenue, retention, market, ROI or fundraising claim presented as fact.
2. Private repositories or credentials required for the user to run/view; unauthorized external publishing, paid subscriptions or sends.
3. Seven source perspectives misrepresented as eight facets, Fusion Field falsely treated as eighth card or as psychometric ground truth.
4. Western and BaZi not distinguished prior to fusion; Wu Xing phases missing, incorrectly named or color-coded with conflicting semantics.
5. Personal agency not illustrated, no valid "not for me"/revision option, shadow treated as moral failure.
6. Broken/not actually rendered 16:9 deck; missing essential deliverables without explicit NOT-RUN reason; false pass claims.
7. Reference images, logos or major compositions literally reused/traced.

## Judged axes (0-5 each, with concrete slide evidence)

| Axis | 5 requires | Failure pattern |
|---|---|---|
| Product specificity | Unmistakable Western+BaZi+5D+human agency visual language recognisable in grayscale | Generic AI nebula, ring, horoscope wheel or fintech cover |
| Emotional pacing | A distinct shift from curiosity through insight into calm, owned meaning and credible opportunity | All slides at one emotional volume |
| Typographic craft | Precise line breaks, strong reading hierarchy, clear main argument in 5 sec | Tiny dense data, chopped headlines, repetitive placement |
| Information graphics | Two source systems and full 5D projection/qualifications are comprehensible to an outsider | Symbolic lines with arbitrary source-to-vector meaning |
| Graphic authorship | At least 2 outstanding original, reusable and semantically earned graphic objects plus 3 hero moments | Stock art, templated abstract or photos masquerading as identity |
| Investor clarity | Segment hypothesis, differentiated wedge, product maturity, validation path intelligible | Brand moodboard disguised as investor story |
| Semantic ethics | Light/Shadow dignified and contextual; rejection is legitimate; no diagnosis/fatalism | Flattery, personality absolutism, unproved self-change claims |
| Visual restraint | Effect density supported by purpose; surprising compositions not clutter | Shadows/neon/glass effects with no meaning |
| Source honesty | Every important claim tagged as source/brief/hypothesis/unknown in notes, no fake metrics | Market and traction invented to fill a slide |
| Execution integrity | Real runnable app, exported screenshots/PDF, keyboard and motion tests recorded | Render assertion without screenshots or exports |

Scoring is a REVIEW AID, not scientific measurement; visual judgments must cite slides. An average score never overrides a blocker. Quality is demonstrated by actual rendered artifacts.

## Design falsification tasks

- Remove logo/color: does iconography still identify distinct source traditions, Fusion Field and open user interpretation?
- Remove lighting and animation: are there still at least five meaningfully different slide compositions?
- Compare 8 source reference screenshots: were only abstract mechanisms transferred, or did the designer copy infinity-shaped blue arcs, TAM bubbles, orange deck branding, green AI-brain, photo diamond masks or gray 3D cubes?
- Pretend to be a skeptical investor: ask "What has been measured?", "What is only planned?", "Why might anyone pay?". Answers must be visible without inventing evidence.
- Pretend to be an astrology skeptic: can one still appreciate the product as a non-clinical language while seeing model assumptions honestly?
- Pretend to be a user who rejects a reading: is that refusal welcomed and persistent? Avoid asserting software features not implemented.
- Read slides at half size: if labels/tables blur into texture, simplify content or improve hierarchy.

## Test / receipt requirements

The coding agent must report at least:
- actual build/test command and exit status;
- count and dimensions of exported slides;
- PDF page count and slide-to-page relation;
- real keyboard navigation observation (or NOT-RUN);
- overflow and readability review with specific fixes;
- at least one before/after revision fact, if revisions happened;
- accessible/reduced-motion fallback status (verify or mark not-run);
- final files and whether PPTX is editable or raster-only.
