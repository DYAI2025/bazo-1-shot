# BAZODIAC — One-Shot External Coding-Agent Package

**Intended use:** build a brand-new, exceptionally high-quality international investor concept deck from code. **Not** an already built deck, and **not** a request to connect Gamma, Confluence, Jira or private repositories.

## Fastest usage

1. Download `BAZODIAC_External_Atelier_OneShot.zip` from the chat and unzip it into the **external coding agent's new, empty workspace**.
2. Paste the **complete content** of `PROMPT_ONE_SHOT.md` as ONE execution instruction (or attach that `.md` if the agent accepts task files).
3. Let it inspect local `BAZODIAC_SOURCE_BRIEF.md`, `REFERENCE_MECHANISMS.md`, `SOURCE_LINKS.md`, eight reference JPEGs, the curated semantic tokens JSON, and the public repo links. No internal credentials or project connections required.
4. The agent should build, render, check and deliver the deck in its workspace in one run. Ask for the actual HTML source, PDF, PNGs and QA report; do not accept a moodboard or a second prompt as fulfillment.

**If only one file can be shared:** paste `PROMPT_ONE_SHOT.md`; it is self-contained with the product mechanics, verified open access sources, narrative and quality gates. Without the ZIP, the attached moodboard may not be visible to the outside agent, and it must not pretend to have inspected the images.

## Contents

- `PROMPT_ONE_SHOT.md`: full executable English prompt; 12-slide investor story, design method, exact production deliverables and QA gates.
- `BAZODIAC_SOURCE_BRIEF.md`: self-contained consumer product and evidence truth. Essential because Confluence and FuFirE repo are not public.
- `REFERENCE_MECHANISMS.md`: eight submitted pitch reference images distilled into transferable mechanisms (not templates).
- `SOURCE_LINKS.md`: verified public GitHub links, private-access exclusions and read-only context.
- `EVALUATOR.md`: independent review checklist with hard blockers and render evidence expectations.
- `source_snapshots/bazodiac_deck_semantic_tokens.json`: semantic color subset of ETBZ design system; the ETBZ PDF look itself is NOT the deck style.
- `references/pitchdeck-example-1.jpg` through `pitchdeck-example-8.jpg`: the user's comparison images, for in-workspace visual inspection only.

## Chosen creative direction

**The Open Meridian:** two *distinct* historical calculation systems, a documented five-phase translation, and an intentionally open region of user-authored interpretation. Images, typography, transitions and layouts derive from this causality, not from a default gradient/CSS library.

**Emotional journey:** intrigue -> felt recognition -> rational comprehension -> self-acceptance with nuance -> freedom to disagree -> recurring exploration -> investor-level falsifiable opportunity.

**Central statement:** *The system offers a language. The individual owns the meaning.*
